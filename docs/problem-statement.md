# Problem Statement

Skin cancer is one of the fastest-growing cancers worldwide.

Most AI skin cancer detection systems are trained primarily on lighter skin tones, which can reduce reliability for Indian and darker skin tones.

There is a need for an accessible AI-powered screening tool that helps users upload a skin lesion image and receive a preliminary risk assessment along with an explanation.

This project aims to develop an AI-based skin cancer detection system with a focus on improving usability and awareness for Indian skin tones.
